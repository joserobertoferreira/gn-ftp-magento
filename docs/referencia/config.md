# app.config

## Configuração

Constantes carregadas do `.env` no arranque. Ver [Configuração](../guia/configuracao.md)
para a descrição de cada variável.

::: app.config.settings
    options:
      show_root_heading: true
      heading_level: 3

## Logging

    options:
